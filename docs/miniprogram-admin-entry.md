# 小程序原生管理后台

- 首页和“我的”页头像连续点击 5 次进入 `/pages/admin/index`；相邻点击间隔不超过 1 秒，离开页面清零。
- 后台使用小程序原生页面与独立分包，通过 `wx.cloud.callFunction` 调用现有 `api` 云函数，无 `web-view`，无需网页业务域名。网页版继续使用现有独立管理页面与布局。
- 店主底部导航为“概览 / 订单 / 其他”；其他包含首页宣传图、项目与款式、精选、技师、排班和门店预约设置。技师仍只访问原有授权范围。
- 左上角“返回小程序”直接切回顾客首页，保留有效管理会话。
- 首次使用现有 CloudBase 管理账号密码登录。云函数验证账号后签发有效期 30 天的随机会话，绑定当前微信账号和小程序；小程序本地仅保存令牌和有效期，不保存密码。服务端仅存令牌摘要，每次操作重新检查账号角色与状态，退出时撤销会话。
- 管理会话复用现有 `idempotency_keys` JSON 表，无需迁移。密码认证只发生在云函数与 CloudBase 身份服务之间；业务操作仍经过现有权限、订单和退款规则校验。五连击本身不授予权限。

## 发布与验证

1. 部署 `api`、`admin-api`，上传当前原项目小程序。
2. `npm run test:admin` 验证手势、账号验证、并发身份隔离、微信账号和小程序绑定、角色限制、过期、撤销、退出与本地会话恢复。
3. `npm test`、小程序页面校验、管理网页构建及 `git diff --check` 均通过。
4. 开发者工具验证真实店主账号登录、读取经营概览和底部页面、返回首页和再次进入恢复会话。手机微信中的扫码、图片选择、支付退款等需真机按实际业务验收；未执行真实业务修改。
